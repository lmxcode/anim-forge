# 踩坑记录（lessons learned）

> 来自真实生产环境的坑，每条都付过时间代价。开新项目前先读一遍。

## 1. 无头浏览器 `--screenshot` 必须用绝对路径

相对路径在部分上下文（heredoc、不同 cwd）**静默失败**——进程退出码 0，但文件根本没写出来。
```python
shot = (out / f"f{i:04d}.png").resolve()   # ✅ resolve() 成绝对路径
```

## 2. 断点续渲的「跳过已存在帧」是一把双刃剑

跳过已有帧让局部重渲成为可能，但也意味着：**删帧操作被中断后，残留的旧帧会被当成有效帧混进成片**。
真实事故：删除 318 张坏帧时中断，只删掉 10 张，重新合成后旧坏画面混入成片，靠抽帧 QC 才拦住。
规矩：删帧后必须验证剩余帧数 == 预期值，再重渲、再合成。

## 3. QC 要抽成片实帧，不能只看探针帧

探针帧（渲染前抽几帧验收版式）能看到 90% 的问题，但成片压缩、缩放后还会暴露新问题。
固定动作：合成后用 ffmpeg 在每个场景中点抽帧 + `volumedetect` 验音量。

## 4. 文字换行劈字，根治法是手动 `<br>` 控断点

CJK 长词（「芯片」「热点」）在大字号下会被浏览器从中间劈开换行。zoom 放大后必现。
探针帧验收时专门盯大字号的行尾。

## 5. 口播超窗的处理顺序

1. 精简文案 → 重新合成（首选）
2. 差 0.2s 以内 → 微挪锚点（锚点只是放置位置，不重录）
窗口判定留 0.15s 余量，宁短勿顶。

## 6. ffmpeg filter_complex 的输入顺序是铁律

`[0]=帧序列 [1]=BGM [2..]=口播段`。amix 的 `inputs` 数 = 1(BGM) + 口播段数，
`normalize=0` 必加（否则多路互拉音量），结尾 `alimiter` 防爆音。

## 7. BGM 与画面对齐的方式

不追求逐帧对齐，对齐「事件」：切场点放 riser、揭示点放 impact、列表逐行放 click。
事件列表写在 config 里，与 anim.html 的 cuts 同源。

## 8. 腾讯系页面截图/采集加 `--virtual-time-budget`

JS 常驻加载的页面（新闻客户端页等）无头截图会挂到超时。加
`--virtual-time-budget=15000` 让虚拟时间跑完后自动退出。

## 9. 走代理的境外站点，headless 浏览器要显式指定代理

`--proxy-server=http://127.0.0.1:PORT`。国内站直连即可，别全局走代理。
